# Contributing

Contributions are welcome, especially reproducible test results and careful documentation.

Please:
1. State the exact phone model and firmware build used.
2. Separate build-time evidence from on-device runtime evidence.
3. Include commands and relevant logs, with personal data removed.
4. Do not submit proprietary firmware images, private keys, or personal identifiers.
5. Do not label an artifact as flashable unless the exact installation and recovery path has been tested.

Kernel-source contributions must respect the upstream project's license and applicable GPL requirements.
